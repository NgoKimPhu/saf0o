# Saf0o 0.1.13

Saf0o 0.1.13 is the first Saf0o release, forked from jorphex/wren 0.1.12. It adds atomic batches through EIP-7702 and
clearer batch reviews.

## Changes

- Added atomic `wallet_sendCalls` batches through an AmbireAccount7702 delegation. The account upgrade is asked inside the
  batch review. Trezor firmware 2.12.5 and later can sign the delegation.
- Added extra account keys for a delegated account.
- Batch reviews show an action card per call, with its own token, ETH and USD balance changes.
- Added native balance previews through dRPC simulation with imported keys. The preview nets the gas fee out of the
  native balance change.
- Saf0o compares the signed bytes with the reviewed transaction before broadcast.
- Added an outbound connection allowlist for the main process.
- Added token import from Alchemy, network lookup on chainlist.org, saving a contract from the review and an address
  copy button on account rows.
- Saf0o asks for app access after an account switch and remembers a declined connection per account.
- Arbitrum uses EIP-1559 fees. Chains without a fee market use a gas price predictor.
- Transaction receipts fall back to `eth_getBlockReceipts` on RPCs that refuse single receipts.

## Compatibility

Use Saf0o Companion 0.1.4. Pairing protocol 3 is unchanged, but the auth domain carries the Saf0o name, so Wren
Companion does not pair with Saf0o.
